# SwiftSnap

A fast, elegant screenshot tool for macOS with a unique innovation: **double-tap Option key to capture**.

## Features (MVP)

- **Double-tap Option** — Instant screenshot trigger
- **Quick annotation** — Arrows, boxes, text
- **Pin to screen** — Keep screenshots floating
- **Fast save/copy** — Clipboard or file

## Requirements

- macOS 13+ (Ventura)
- Accessibility permission (for keyboard monitoring)
- Screen Recording permission (for capture)
